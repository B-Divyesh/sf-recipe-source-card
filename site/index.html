How it works

See every step from page to card.

The extension shows the fields it finds. You decide what to change before export.

  1. 01

    Read the published recipe

    Open a recipe page and choose Capture recipe. The extension reads its exposed Recipe JSON-LD.

  2. 02

    Edit the card

    Review the ordinary labeled fields. Fix the name, yield, ingredients, steps, or times.

  3. 03

    Export with the source

    Download Markdown or JSON. Both files include the publisher URL and capture date.

What it does not do

No guessing from hidden page text.

The extension uses structured recipe data that the open page publishes. It does not crawl links or bypass access controls.

Always review allergen, temperature, and food-safety details before using a captured card.

Install the extension

Load it in Chromium.

  1. 1

    Download and unzip the extension package.

  2. 2

    Open chrome://extensions. Turn on Developer mode.

  3. 3

    Choose Load unpacked. Select the unzipped folder.
